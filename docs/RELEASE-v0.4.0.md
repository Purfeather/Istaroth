Istaroth 0.4.0 增加黑屏幕布旁白自动继续，沿用“自动推进对话”开关。

### 本版更新

- 识别旁白的独立继续控件，通过已校验的按钮事件推进。
- 按交互实例去重，并检查观测连续性。每次交互只提交一次，控件明确失活后才允许下一次。
- 菜单打开、暂停、失焦与 F10 沿用现有执行许可。

### 下载与使用

- 下载 **Istaroth-v0.4.0-win64.zip**，完整解压到独立目录，阅读 **使用说明.txt**。请勿放入原神安装目录或其子目录。
- 更新前完全退出游戏和加载器。首次打开加载器后手动启动游戏，加载成功后会记住路径；后续可由加载器启动游戏。
- 用 Insert 开关菜单，点击“启用”后关闭面板以开始。F10 停止功能并请求恢复原速。
- 遇到问题可从 [v0.2.0 Release](https://github.com/Purfeather/Istaroth/releases/tag/v0.2.0) 下载独立报告工具。

### 验证范围

用户已完成七文件候选包实机验收，莎莎练习笔记及同段剧情后续幕布均正常推进。发行包从相同运行源码重新构建，更新版本标识与随包说明；具体构建、离线回归和 CI 结果记录在附件发布清单中。重新构建的发行文件尚未另行实机复测。

其他剧情，以及同一控件持续活动、仅替换正文的多页界面，尚未单独验证。遇到未自动推进的“点击后继续”，请手动继续。首次对话前的纯过场可能保持原速。支持的游戏版本以 [兼容指纹](../profiles/compatibility.json) 为准。
