# 故障排查

- **首次使用未记录路径**：启动加载器后手动运行原神；加载器在收到初始化成功确认后会自动记录游戏路径并退出，无需手动选择文件。
- **游戏路径失效或需重选**：退出游戏和加载器，编辑 `Istaroth.ini`，将 `[Istaroth]` 下的 `GamePath` 项留空保存，重新运行加载器即可重新引导。
- **版本不匹配提示**：当前游戏版本与内置兼容指纹不符时会自动拒绝注入，需等待更新适配，请勿尝试跳过校验。
- **注入失败或错误 126**：确认已完整解压且四个功能 DLL 位于同级目录下；可查阅 `Istaroth-injector.log`、`Istaroth-injector-result.json` 及 `Istaroth-runtime.log` 查看具体失败阶段。
- **游戏内提示加载异常**：按 F10 停止功能，正常退出游戏后重新按流程启动；请勿在游戏运行中直接覆盖或替换 DLL 文件。
- **Insert 菜单无法唤起或鼠标无法操作**：确保游戏处于窗口化或无边框窗口模式，检查是否有其他覆盖层抢占焦点；关闭菜单会自动恢复游戏原有鼠标状态。
- **紧急停止功能**：按 F10 键可立即重置倍率并停用功能；关闭加载器窗口不会卸载游戏内已加载组件。

**问题反馈提示**：反馈时请注明工具版本、游戏版本指纹、显示模式及问题复现步骤；日志与截图建议事先遮蔽个人 UID 及路径账号信息。
