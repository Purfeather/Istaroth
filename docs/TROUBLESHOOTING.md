# 故障排查

- 首次没有游戏路径：先开加载器，再手动启动原神；无需选择文件。只有收到初始化成功确认才会保存路径。
- 路径失效：正常退出游戏和加载器，编辑 Istaroth.ini，将 [Istaroth] 下 GamePath 留空，再执行首次流程。
- 版本不匹配：不要禁用校验或复制其他版本配置，等待相应版本适配。
- 加载不完整／错误 126：确认完整解压且四个 DLL 齐全，查看 Istaroth-injector.log、Istaroth-injector-result.json 与 Istaroth-runtime.log；错误码本身不足以断定原因。
- 菜单已出现但提示失败：F10 停止功能，正常重启游戏后再加载；不要在当前游戏内替换文件并重复加载。
- Insert 菜单无法操作：确认窗口化或无边框，留意其他覆盖层与焦点；关闭菜单应恢复先前鼠标状态。
- 需要停止：按 F10；关闭菜单与关闭加载器并不等于卸载 DLL。

反馈附版本、游戏指纹、窗口模式、复现步骤和脱敏后的错误阶段。不要直接上传完整配置、日志或带 UID 的截图。
