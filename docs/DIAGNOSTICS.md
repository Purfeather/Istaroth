# 开发版诊断与全屏验证

待发布版本为 `0.2.0`，整合此前 dev.1、dev.2 的诊断与 DXGI 改进。正式回退版本仍为 v0.1.1，既有开发包保留。

## 保存和提交错误报告

发生问题后，可单独下载“伊斯塔露报告工具.exe”，无需终端或安装额外组件：

1. 双击打开报告工具，点击“选择文件夹”，选择放有 `Istaroth.exe` 的文件夹，不是游戏目录。放在 Istaroth 同目录运行时会自动选中。
2. 点击“导出报告”。报告保存到桌面的 `Istaroth-reports` 文件夹，重复导出不会覆盖旧报告。
3. 点击“打开报告位置”，将选中的 TXT 文件连同弹窗截图发送给开发者，并说明报错时间和当时操作。

报告工具独立于七文件安装包，只需在排查问题时下载；许可证与版权声明可在窗口中查看。导出不启动游戏，不修改原配置或日志，也不会自动上传。原日志无法读取时，报告会标注缺失或读取错误；如遇受保护的日志目录，可右键以管理员身份运行。旧版未记录的详细运行信息无法事后补齐。

报告工具有独立版本号，报告中的 `collector_version` 表示报告工具自身版本；被收集的 Istaroth 版本以原日志标识为准，不根据报告工具版本推断。

开发版原有的命令行导出入口仍可使用：

```powershell
.\Istaroth.exe --diagnostics
```

加载器会在 `reports` 文件夹生成一份带时间戳的 UTF-8 文本报告，并显示保存位置。该入口无需启动游戏，缺少某份日志或组件也可以导出。静默导出可使用 `--diagnostics --quiet`；退出码 0 表示成功。

报告包含 Windows 版本、功能配置、组件文件大小和现有工具日志。命令行入口还记录构建版本、源码提交及支持的游戏指纹；独立报告工具不核验游戏指纹。不会复制配置文件中的游戏路径或其他配置段；复制日志时会替换已知的游戏路径、工具目录和当前用户目录。发送前可打开文本检查内容，并填写报错时间、时区、弹窗文字和当时场景。

`Istaroth-runtime.log` 和 `Istaroth-injector.log` 各达到 512 KiB 后轮换，保留一份 `.1` 备份。每行记录 UTC 时间、进程和线程、版本及源码标识。运行日志在状态变化时记录，并每 5 秒补充状态快照，包含功能开关、倍率、对话判定、组件错误与渲染状态。

这些记录用于确认故障前最后完成的阶段。进程直接退出、被外部结束或驱动异常时，日志不一定包含异常堆栈；本版不安装全局异常处理器，也不生成游戏内存转储。需要时另附 Windows 可靠性监视器中的技术详细信息。

## DX11 菜单

开发版通过 DXGI 帧回调将菜单和 HUD 绘制到目标游戏交换链，使用原游戏窗口接收菜单输入。打开菜单不激活独立窗口、不改变游戏显示模式。关闭菜单或切换到其他应用时恢复此前的鼠标状态，功能恢复仍经过原有控制器核验。

回调安装、首帧初始化、图形状态保存与恢复、缓冲区尺寸变化、设备失效和交换链释放都有对应日志。初始化未完成时不会报告成功。

dev.2 以 UNORM 视图绘制已有 sRGB 调色板，修正 sRGB 游戏后缓冲区上的重复编码。毛玻璃在 GPU 上复制绘制 UI 前的游戏帧，经四分之一宽高降采样、线性光水平和垂直模糊后，显示在面板与 HUD 的圆角底层；文字、图标和控件保持清晰。收起菜单时仅复制、处理 HUD 周围带模糊边距的区域，展开时处理全画面。着色器和纹理嵌入现有组件，无新增初始发行文件。

模糊资源在尺寸变化或设备重建时更新；不支持的格式或资源创建失败时保留半透明底色，并记录 `blur_unavailable`，不因此停用剧情功能。`ui_color_target` 记录实际 UI 视图格式。SDR RGBA / BGRA、sRGB 与多重采样由自有 GPU 宿主验证，HDR 材质与实际游戏性能尚未验收。

## 验证范围

自有宿主使用隐藏窗口和真实 WARP DX11 交换链检查帧回调、图形状态恢复、菜单消息处理、鼠标状态、尺寸变化和交换链重建；设备失效采用模拟返回值。鼠标与焦点 API 在宿主中模拟，不向桌面发送输入。

以下项目需实机验收后才能确认：

- 游戏的实际交换链能否完成首帧初始化，加载器是否正确收到确认。
- 真正独占全屏下 HUD 可见，Insert 打开菜单时保持游戏画面与焦点。
- 菜单按钮、滑块及开关可操作，菜单打开时游戏不会继续响应这些输入。
- Insert／Esc 关闭菜单、Alt+Tab 切换应用及恢复后，鼠标显示、位置与限制正确。
- 游戏内切换分辨率、窗口化、无边框和独占全屏后，菜单能够继续工作。
- 长时间运行、退出游戏及再次启动后的表现；本版不代表已解决其他用户报告的 `(2,0,4)` 退出问题。
