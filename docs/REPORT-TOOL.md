# 伊斯塔露报告工具 0.1.0

用于收集 Istaroth 已有日志的独立 Windows x64 图形工具，只需在出错后下载。

1. 双击下载的报告工具 EXE，Release 附件名为 Istaroth-ReportTool-v0.1.0-win64.exe，窗口为中文界面。
2. 点击“选择文件夹”，选择包含 `Istaroth.exe` 的文件夹，不是游戏目录。同目录运行会自动选中。
3. 点击“导出报告”，然后点击“打开报告位置”。
4. 将选中的 TXT 连同报错截图发送给开发者，说明报错时间和当时操作。

报告保存到桌面的 `Istaroth-reports` 文件夹；每次导出使用不同文件名。工具不自动上传，不启动游戏，不修改原配置或日志。报告内容可在发送前自行查看。

报告只复制固定的 Istaroth 日志文件、功能配置摘要与组件文件大小。缺失或无法读取的日志会在报告中标注；如日志目录受保护，可尝试右键以管理员身份运行。旧版本没有记录的信息无法补收，报告不包含游戏内存转储或异常堆栈。

许可证与版权声明内嵌在 EXE 中，可点击“许可声明”查看。该工具单独分发，不计入七文件安装包。完整说明见 [诊断说明](DIAGNOSTICS.md)，构建方式见 [构建说明](BUILD.md)。
