# 质量更新与验收边界

## v0.2.0 七文件版本（待发布）

主包在原五组件与 LICENSES.txt 之外新增使用说明.txt，合计七个初始文件。说明写明放置位置、首次等待游戏启动、日常启动和按键；配置与日志按需生成。独立图形报告工具单独分发。

此版本整合 DX11 帧内菜单、毛玻璃和配色修正。此前 dev.2 视觉试用已获用户认可；0.2.0 重新构建后的产物、离线验证与实机验收分别记录，不沿用旧包哈希作为新包验收依据。

## v0.1.1 六文件版本

初始 ZIP 仅 Istaroth.exe、Istaroth.dll、time_core.dll、story_probe.dll、dialogue_actions.dll、LICENSES.txt 六文件。默认 PNG 嵌入驻留组件；assets/istaroth-mark.png 是可选覆盖，不必携带。INI 原有读取逻辑缺省即默认值；路径只在初始化成功后写入，设置变更时按需保存。日志仍保留。

2026-11-13，用户完成实机测试，确认首次启动、路径与配置保存、菜单和鼠标恢复正常，正式登记为 v0.1.1。原测试包及 v0.1.0 版本归档均完整保留。多屏高分屏、复杂覆盖层组合等边界场景纳入后续跟踪测试。
