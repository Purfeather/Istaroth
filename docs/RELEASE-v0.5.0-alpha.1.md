Istaroth 0.5.0-alpha.1 新增国际服适配，感谢 @ChiyukiKazama 的 PR #2。

### 更新内容

- 支持配置中列出的国服 YuanShen.exe 与国际服 GenshinImpact.exe，并分别核对文件指纹。
- 分离两服的对话、剧情探测和时间控制配置，统一代码特征校验。
- 适配国际服方法布局、对话推进与冷却逻辑，调整组件启动顺序。
- 扩展国际服加载器模拟测试与方法查找、冷却逻辑离线测试。

### 验证与已知问题

本版为预发布测试版。维护者没有国际服客户端，国际服实机测试与后续适配需贡献者协助。本版国服也尚未实机复测。离线构建与测试结果随发布附件提供。

审查中发现的两个 P2 问题仍待跟进。
- 首次启动提权交接时，若另一服先出现，可能选中另一服并保存其路径。
- 离线模拟会跳过正式版部分组件就绪等待，尚未覆盖完整启动顺序。

### 使用

完整解压 ZIP 到游戏目录之外的新文件夹，阅读包内使用说明。Insert 打开菜单，F10 停止功能。稳定版 v0.4.1 仍可从历史发行版下载。
