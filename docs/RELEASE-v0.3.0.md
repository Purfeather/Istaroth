Istaroth 0.3.0 更新了设置面板和 HUD，并修复游戏的 D3D11 条件渲染状态可能造成的界面闪烁。

### 本版更新

- 绘制界面时隔离游戏的条件渲染状态，绘制完成后恢复，解决面板与 HUD 可能同时消失的问题。
- 修复按住右上角 X 后松开时可能无法关闭菜单的问题。菜单在 HUD 下方收放，关闭时立即归还键鼠。
- 更新月牙与星形图标、字体和中文状态提示。面板显示配置和暂挂状态，HUD 区分暂停、待命、运行与故障。倍率卡片显示目标倍率。

### 下载与使用

- 下载 **Istaroth-v0.3.0-win64.zip**，完整解压到独立目录，阅读 **使用说明.txt**。请勿放入原神安装目录或其子目录。
- 更新前完全退出游戏和加载器。首次打开加载器后手动启动游戏。后续可由加载器启动已记住的游戏。
- 用 Insert 开关菜单，点击“启用”后关闭面板以开始。F10 停止功能并请求恢复原速。
- 遇到问题可从 [v0.2.0 Release](https://github.com/Purfeather/Istaroth/releases/tag/v0.2.0) 下载独立报告工具。

### 验证与限制

X 按钮和调整后的菜单收放已由用户试用。单独验证闪烁修复的 A 版连续约三分钟未复现。正式包由筛选后的源码重新构建，组合版本的实机表现、独占全屏、HDR 及其他覆盖层组合仍待复测。

黑屏旁白的“点击后继续”仍需手动操作。首次对话前的纯过场可能保持原速。支持的游戏版本以[兼容指纹](../profiles/compatibility.json)为准。
