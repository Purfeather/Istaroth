# 幕布旁白自动推进

v0.4.0 沿用“自动推进对话”开关，为黑屏幕布旁白加入继续请求。2026-11-21 用户完成候选包验收，确认莎莎练习笔记及同段剧情后续幕布均正常推进。发行与验证范围见 [发布说明](RELEASE-v0.4.0.md)。

## 实现

真实游戏的进入、等待和退出记录表明，这一页使用活动的 `MonoClickContinue`，它引用一个 `Button`。此前只查常规对话推进按钮，遗漏了这一独立控件；`MonoCurtainCanvas` 在本页并不活动。

通过现有主线程执行器调用该按钮的 UnityEvent。继续前要求：唯一且有效的活动实例、已确认的对话上下文、普通推进标志为零、无活动选项、按钮与事件元数据校验通过，以及新鲜的执行许可和游戏前台状态。菜单、暂停和 F10 沿用现有许可控制。

状态需被持续观察至少 500 毫秒；观测空档超过 250 毫秒或状态未知时重新计时。许可可以在提交时恢复，暂停期间观察时间可以累计。每个交互实例仅提交一次，只有同一实例明确失活才能解除锁定；点击无效、采样缺失或菜单切换均不触发重试。

## 验证

- 全量构建与 17 组离线回归通过，包含实例有效性、过期数据、错误进程/ABI、多个实例、未知状态、观测中断和去重测试。
- 研究版在莎莎笔记实机记录到影子请求标记，尝试和完成计数均为零，画面仍在笔记页。
- 实际动作组件随后在实机完成一次内部继续事件，尝试 1 次、完成 1 次；画面回到派蒙首句，同一控件失活。立即暂停，此后没有继续输入。
- 上述研究取证轮次始终为原速，未加载整个驻留菜单包。动作组件的实测 SHA-256 为 `01031799d8137783f7288cac3e90211f34ca5b6b417e456ff18445a3680e70ea`。
- 用户随后试用七文件候选包并反馈：“验收完成。此段剧情后续还有其他的幕布过场，生效正常。”该复测扩大了已通过的场景范围，详见 [用户验收记录](accepted-curtain-20261121.json)。

## 待验证

已通过范围包括莎莎笔记及同段剧情后续幕布。其他剧情，以及同一控件不失活而只替换正文的多页路径，尚未单独验证。当前身份是控件实例，不是正文页号；若同一实例持续活动而只替换正文，会停在第一次请求后，保留手动继续。

游戏版本仍受兼容指纹限制；本候选没有扩大加速状态的识别范围。使用、放置位置和许可见主 README 及随包说明。
