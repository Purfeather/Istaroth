# 幕布旁白开发候选

基于正式版 v0.3.0。本候选沿用“自动推进对话”开关，为莎莎练习笔记的黑屏旁白加入一次继续请求。尚未合并或发布。

## 实现

真实游戏的进入、等待和退出记录表明，这一页使用活动的 `MonoClickContinue`，它引用一个 `Button`。此前只查常规对话推进按钮，遗漏了这一独立控件；`MonoCurtainCanvas` 在本页并不活动。

候选通过现有主线程执行器调用该按钮的 UnityEvent。继续前要求：唯一且有效的活动实例、已确认的对话上下文、普通推进标志为零、无活动选项、按钮与事件元数据校验通过，以及新鲜的执行许可和游戏前台状态。菜单、暂停和 F10 沿用现有许可控制。

状态需被持续观察至少 500 毫秒；观测空档超过 250 毫秒或状态未知时重新计时。许可可以在提交时恢复，暂停期间观察时间可以累计。每个交互实例仅提交一次，只有同一实例明确失活才能解除锁定；点击无效、采样缺失或菜单切换均不触发重试。

## 验证

- 全量构建与 17 组离线回归通过，包含实例有效性、过期数据、错误进程/ABI、多个实例、未知状态、观测中断和去重测试。
- 研究版在莎莎笔记实机记录到影子请求标记，尝试和完成计数均为零，画面仍在笔记页。
- 实际动作组件随后在实机完成一次内部继续事件，尝试 1 次、完成 1 次；画面回到派蒙首句，同一控件失活。立即暂停，此后没有继续输入。
- 上述实机运行始终为原速，未加载整个驻留菜单包。动作组件的实测 SHA-256 为 `01031799d8137783f7288cac3e90211f34ca5b6b417e456ff18445a3680e70ea`。

## 待验证

此结果覆盖莎莎单页笔记。其他使用同类控件的界面、连续多页和完整菜单包与倍率组合尚待实机验收。当前身份是控件实例，不是正文页号；如果同一实例持续活动而只替换正文，候选会停在第一次请求后，保留手动继续。

游戏版本仍受兼容指纹限制；本候选没有扩大加速状态的识别范围。使用、放置位置和许可见主 README 及随包说明。
