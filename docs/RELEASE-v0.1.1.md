# Istaroth v0.1.1

本版将初始发布包精简为六个文件：加载器、四个 DLL 和一份完整许可说明。默认 HUD 图标嵌入驻留组件，支持可选的外部图片覆盖；配置与日志按需生成。

2026-11-13，用户实机测试确认首次启动、路径与配置保存、菜单和鼠标恢复正常，正式登记为 v0.1.1。测试归档与各组件哈希保持不变，详见 [验收记录](accepted-v0.1.1.json)。

功能特性与限制说明参见项目 README。当前支持窗口化及无边框窗口模式；对话首句前的纯过场暂不加速。

Istaroth 是独立第三方项目，与米哈游（miHoYo／HoYoverse）无隶属、合作、授权或背书关系。原创代码遵循 Apache-2.0 许可证，第三方依赖及角色二次创作素材遵循各自的许可与权利说明。

本版本通过私有仓库分发。安装包沿用已验收归档，保留原有候选文件名；不以 CI 重建产物替换。
