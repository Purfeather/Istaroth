# Istaroth v0.1.0

首个准备公开的版本，包含对话 1–4 倍推进、自动推进、自动选择首项、跳过对话冷却、游戏内菜单与 HUD。

首次启动：先打开加载器，再手动启动原神；初始化成功后记住路径并退出。后续直接打开加载器即可启动已记住的游戏。默认暂停，Insert 菜单，F10 停止。

用户已验收当前加载器首启／记路径／再次启动流程及此前菜单、鼠标改进。此发行 ZIP 的五个可执行组件与该验收原包完全相同，仅整理说明、许可与元数据。源码重建产物另行验证，不能与本次用户验收等同。

限制：Windows x64，指定 YuanShen.exe 指纹；窗口化／无边框；首句前纯过场可能不加速。无传送、独占全屏、实时背景模糊或抗更新保证。不承诺账号安全或免封。

下载项：Istaroth-v0.1.0-win64.zip、同名 sha256 与 manifest.json。完整解压，不混用旧 DLL；升级前正常退出游戏。
